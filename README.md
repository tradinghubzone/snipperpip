# 🤖 US500 Snipper AI Bot — 1H Timeframe Scanner

A clean, responsive web-based UI that simulates an **AI trading bot** scanning the **US500** index on a **1-hour timeframe**. It detects "snipper" entries, calculates **Stop Loss (SL)** and **Take Profit (TP)** at 200 pips, and includes an **MT5-style countdown** that resets every hour — just like the next candle open on MetaTrader 5.

> ⚠️ **Disclaimer:** This is a **UI/UX demo and simulation**. It does **not** connect to a real broker, MT5 terminal, or live market feed. No real trades are placed. Use it for prototyping, design inspiration, or as a starting point for a real trading bot.

---

## 🚀 Features

- ✅ **US500 (S&P 500) symbol** with live-style price ticker
- ✅ **1-Hour timeframe scanner** (signal refreshes every 3600 seconds)
- ✅ **Snipper entry** – AI-detected LONG / SHORT direction
- ✅ **Automatic SL / TP calculation** – 200 pips from entry
- ✅ **MT5-style countdown timer** (HH:MM:SS) with progress bar
- ✅ **Manual "NEW SNIPER" button** to force a new scan
- ✅ **AI confidence indicator** (dot-based signal strength)
- ✅ **Fully responsive** – desktop, tablet, and mobile friendly
- ✅ **Clean glassmorphism UI** with smooth animations
- ✅ **Pure HTML + CSS + JavaScript** – no frameworks, no dependencies (except Google Fonts + Font Awesome)
